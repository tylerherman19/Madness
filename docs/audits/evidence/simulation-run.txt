When the run happens on a Thursday or Saturday, the simulation slides the stored slate dates back one day only for the duration of the lock-time assignment run on a round's second day (World.withRealWeekday), matching a real Friday or Sunday. This run was on a Thursday. No application code was changed.
- 100 entries registered over HTTP (bcrypt 12); 900 were inserted by SQL (bcrypt cost 4). All 1,000 signed in over HTTP.
- Workers were invoked through /api/cron/worker with every call required to report claimed:true.
